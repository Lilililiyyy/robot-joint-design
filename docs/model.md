# 模型、公式与验证边界

[中文](model.md) · [English](model.en.md)

本项目为新写降阶工程模型。独立可运行、方程核验、原版数值对标与物理试验是分别登记的状态。

## NGW运动学与载荷坐标

固定内齿圈，太阳轮输入、行星架输出。零变位同模数直齿满足`zr=zs+2zp`，速比`i=1+zr/zs`；均布行星装配要求`(zs+zr)/N`为整数，相邻行星齿顶圆须有正间隙。

`geometry.undercut_screen`另作标准全齿高零变位齿条的外齿根切风险初筛：齿顶高系数`ha*=1`时，理论条件为`z sin²α>=2`，连续阈值为`2/sin²α`。公式参考[QTC/KHK技术资料](https://www.qtcgears.com/tools/catalogs/PDF_Q420/Tech.pdf)。它只用于太阳轮与行星轮，不自动否决方案，也不检查实际刀尖圆角、齿根过渡、内齿干涉和尖顶。装配成立与该初筛通过均不能替代制造齿形校核。

输出六分量载荷给定于载荷端口，采用设计需求符号：`output_wrench.Mz`与`output_torque_n_m`同值同号；正负T选择工作面，`T·ω`选择驱动或回驱。实测反力应先按作用/反作用和坐标转换到该约定，不能直接与设计需求混用。

定义载体半径`R=rs+rp=(rs+rr)/2`，每条路径的两副参考圆切向力幅值为`ft`。行星转动平衡使两副ft相等，销受切向力`2ft`，因此`Tout=2R Σft`。太阳和环的力矩分别为`rs Σft`和`rr Σft`。每副法向力`Fn=ft/cosα`。

路径虚功关系为`Tout dθout=Σft d(2R θout)`。齿面法向位移δn对应切向等效位移`δn/cosα`，所以啮合路径柔度为`1/(kn cos²α)`。销位移为`2ft/kpin`，虚功映射再乘2，得到路径柔度`4/kpin`。

太阳共享二维平移使用支承Ksun；第j颗行星的径向/切向单位矢量为rj/tj，载荷方向s=±1。`Dj=tj+s tanα rj`，共享路径柔度`Csun=D Ksun^-1 Dᵀ`。太阳受力`-s Dᵀf`，内齿圈径向项符号相反；与销受力满足合力与合矩平衡。

## 单边路径与齿面协调

路径模型解互补能最小化：`min (fᵀCf/2+gᵀf)`，约束`f>=0, Σf=|Tout|/(2R)`。载荷乘子为路径接近量，各承载路径位移相同；未承载路径不穿透，活动集合允许脱开与重入。

每条路径柔度为两副齿面、销和太阳共享平移及外部凝聚柔度之和。输出端局部刚度`Kout=(2R)²·1ᵀCactive^-1·1`。结构6×6刚度表示另外的串联结构，先变换为输出载荷端口柔度`Cport`，再用其`Cport[5,5]`与`1/Kout`相加；不能重复放入同一齿面/支承柔度。

给定逐行星局部载荷，LTCA计算每副一个完整啮合周期的接近量和切线刚度。对周期平均位移，切线取各相位柔度平均的倒数。每副下一次线性化截距为`δmean/cosα−ft/(kn cos²α)`，两副相加到路径误差。外迭代同时检查力变化和真实路径位移残差，避免只让力平衡而未满足位移协调。

LTCA沿用公开内核的几何、结构近似、单边载荷和局部Hertz压力模型；ISO模式不重复叠加Hertz压陷。评级参数在局部增量刚度中冻结。系统模型采用周期平均，不求同步啮合相位的整机动态载荷。加载角包含给定路径误差和修形的基准偏移，应理解为承载传动滞后量；独立自由侧隙另计。

## 支承与轴承

结构关系`K uref=Wref`要求消除刚体模态后互易正定。`support.reference_offset_m=h`是从K参考点到输出载荷端口沿+z的有符号距离，缺省0。令`r=[0,0,h]`，端口位移`uport=B uref`，其中平移为`uref,trans+θref×r`；虚功要求`Wref=Bᵀ Wport`，即`Mref=Mport+r×F`。因此端口柔度为`Cport=B K^-1 Bᵀ`。先在K参考点求解，再把端口位移传给精度与失准映射，不能漏掉悬伸力臂产生的倾转。

两个输出支承位于各自中点坐标的z=±L/2。`bearings.load_offset_m`另行定义该中点到载荷端口的z距离，先平移力矩再求反力；绕轴Mz由传动链承担，不由双径向支点抵抗。该偏置独立于结构K偏置：K已凝聚于端口时，`support.reference_offset_m=0`仍可对应非零轴承偏置。当前案例明确采用这一选择，工程导出分别登记各参考点。

轴承基本额定寿命`L10=(C/P)^p`百万转，球轴承p=3、滚子p=10/3。每段转数`n=|ω|dt/(2π)`，损伤`D=Σ(P/C)^p n/10^6`；基本小时寿命为整个任务时长除以3600D。P=XFr+YFa、P0=X0Fr+Y0Fa的目录系数由调用者给定。[NSK官方寿命说明](https://www.nsk.com/tools-resources/abc-bearings/dynamic-load-ratings-and-fatigue-life/)支持基本公式；[Schaeffler技术手册](https://www.schaeffler.com/remotemedien/media/_shared_media/08_media_library/01_publications/schaeffler_2/catalogue_1/downloads_6/stt_de_en.pdf)说明目录分支与系数的重要性。

该模型不含预紧、游隙、可靠度/润滑/污染修正、小角摆动接触覆盖、微动磨损或假压痕；零速仅不产生本模型中的滚动疲劳损伤，仍须静校核。

## 雨流与有限寿命

新写峰谷栈算法保留开放序列残余半循环。两组[MathWorks公开表](https://www.mathworks.com/help/signal/ref/rainflow.html)作为独立数值参考，不调用MATLAB。应力幅值`σa=range/2`，S-N曲线`N=Nref(σref/σa)^m`，Miner损伤`D=Σcount/N`。可选Goodman张拉均值修正`σa,eq=σa/[1−max(σmean,0)/Su]`，压均值不获益是显式工程约定，参考[COMSOL均值修正说明](https://doc.comsol.com/6.3/doc/com.comsol.help.fatigue/fatigue_ug_sme.4.28.html)。

时程须为Pa。没有多轴折算、材料数据库、耐久极限或所有齿的真实受载历程生成。输出的运动学接触机会数不能直接替代疲劳循环数；截断序列重复前应按真实顺序拼接计数，不能将分段独立闭账自动当成连续时程。

给定谱的损伤现在进入方案初筛，缺省限值`D<=1`；可在`design_limits.fatigue_damage_per_input_history`给定上限。它只表示这个明确输入的标量谱，不能由此生成整关节目标服役寿命，也不把未配置疲劳视为通过。

## 机电、精度与热

电机转速`ωm=iωout`。驱动反射负载力矩`Tout/(iηf)`，回驱`Toutηb/i`，零速以理想`Tout/i`计算保持电流，再加转子惯量`Jm i αout`。驱动与回驱损耗由输入/输出功率差得到；铜耗I²R，Kt/R必须采用同一电流基准。静态制动检查采用输入侧理想载荷力矩乘给定安全系数，不利用摩擦自锁获益，不代表动态制动认证。

精度是确定性未补偿预算：承载角绝对值＋总侧隙/2＋输出等效编码器半计数＋装配误差绝对值。双工作面静态包络不记录摩擦历史，不冒称实测迟滞。

两节点热网络`C θdot=P−G θ`，G包含两个对环境热导及节点耦合热导。分段恒损耗用矩阵指数精确推进；温度是两个实指数之和，检查导数内部零点与端点求峰温。周期模式合成`θend=Aθ0+b`，解`(I−A)θ0=b`，再分析完整周期，检查周期边界与能量平衡。[SciPy矩阵指数文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.expm.html)提供独立数值核验方法。

热容、热导、效率和损耗参数均由调用者输入。首版不包含电阻随温度反馈、润滑预测和空间温度场。

## 设计判定与覆盖

新增最小输出扭转刚度、最大均载系数和给定热点谱损伤约束，字段见[接口说明](api.md)。当前案例的`Kout>=20000 N·m/rad`、`Kγ<=2`及`D<=1`均为新增设计假设，不是DFKI原产品规格。案例采用64相位×26条带；离散研究与对标须沿其明确的工况和指标解释，不能把一个代表工况的收敛扩大为全部载荷及几何的证明。

`summary.check_details`逐项记录实际值、限值、比较方向、状态与适用范围。缺参数的项目为`not_evaluated`，有评价值但未设限值的项目为`not_configured`，均不计作已通过。`summary.assessment_coverage`另行登记模型未覆盖项，因此`configured_checks_pass=true`仅表示已评价约束通过。

行星销等效刚度不是销强度；两个输出轴承的基本L10不包括行星轴承；功率平衡不证明母线吸能或驱动器电流/电压能力。内齿圈轮缘、行星架、壳体、预紧/配合、润滑与摆动损伤、扭振和控制带宽尚需相应模型或试验。修订项、测试与后续优先级见[设计审查](design_review.md)。

## 验证层级

新写模块有解析、方程、公开参考表、数值一致性及接口测试；复用齿轮内核另有有限范围原版对标基础，当前可复算的对标及离散证据见[验证说明](validation.md)。厂商原始数值一致、独立公式核验、实物公开参数核对和实体试验是不同层级。当前没有新写系统层的商业软件总成数值对标或样机精度验证；示例是可复算的工程流程，不是经过标定的实体关节产品。
