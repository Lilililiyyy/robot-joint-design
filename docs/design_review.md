# 设计准则与工程边界

[中文](design_review.md) · [English](design_review.en.md)

关节设计以任务需求为起点，依次检查传动载荷、齿面与支承、驱动和能量、精度与热性能。每项判定绑定明确输入及限值，未配置或未评价的项目单列。

## 设计判据

|对象|判定要求|
|---|---|
|行星传动|满足装配和空间间隙；非负路径力；逐行星力矩与位移协调|
|齿轮强度|显式因子下的齿面/齿根安全系数达到要求；检查标准齿条假设下的外齿根切风险|
|刚度与精度|输出扭转刚度、均载系数、承载角及侧隙满足设定目标|
|结构支承|力作用点与刚度参考点明确，使用保持虚功的坐标变换|
|行星销|弯曲、横剪、平均孔压及挠度分别评价；几何刚度与系统输入保持一致|
|轴承|按实际反力和相对转速作基本评级，摆动工况另行评价|
|机电与制动|检查转矩—转速包络、RMS电流、零速保持损耗和静态制动要求|
|再生能量|按电功率计算回馈、电容缓冲及吸收能力，检查电压约束|
|热与疲劳|在给定热参数、损耗和S-N数据下评价周期温升及累计损伤|

结果使用`passed`、`failed`、`not_configured`、`not_evaluated`四种状态，保存实际值与限值。已配置判据通过表示当前模型下满足输入要求。

## 案例中的设计选择

6:1案例选取`Kout≥20000 N·m/rad`、`Kγ≤2`、给定热点谱`D≤1`。这些是本例设计目标，新增修形、刚度、热参数和许用值均为显式假设。

4/6 mm假定行星销在相同载荷下静强度均满足给定要求，但平均弯剪刚度分别为71.225/297.707 MN/m。集成方案选择6 mm销，并将计算刚度反馈至系统重新分配载荷，避免仅根据应力选择尺寸。

母线在36 V源、48 V上限和给定逆变效率下比较电容与吸收能力；集成方案采用4700 μF，计算最高电压约43.194 V。详细输入和公式见[行星支承](planet_support.md)、[母线模型](dc_bus.md)。

## 接触与精度的解释

通过程峰压图、瞬时局部接触带、标准评级应力和输出角度预算分别解释。直齿零齿廓修形时的单双齿分担切换可以形成压力分区；改变修形或柔度后须重新求解。参数级CAD/BOM用于后续结构接入，尚不直接构成制造图样。

## 后续工程工作

|工作|所需设计输入或实物依据|
|---|---|
|双向刚度、回差和摩擦标定|正反扭矩—角度曲线及装配状态|
|实际销孔、轮缘、行星架与箱体|实体结构、配合、预紧及三维结构分析|
|轴承选型与摆动服役|采购参数、摆幅、润滑及磨损要求|
|效率与温升标定|电流、转速、温度和损耗测量|
|驱动与吸收硬件|电源能力、电压/电流包络、保护和电阻热容量|
|制造与装配|公差链、材料热处理、齿面质量及验收要求|

工程公式见[模型](model.md)，完整使用流程见[案例](examples.md)。
