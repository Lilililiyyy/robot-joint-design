# 关节模组设计审查与完善

[中文](design_review.md) · [English](design_review.en.md)

本次审查从机器人关节的设计需求、功率/载荷传递、刚度精度、失效模式和验证证据出发，检查参数化计算内核及其公开案例。审查结论支持将项目用于**单级直齿NGW关节的准静态设计计算与方案筛选**；完整实体设计、制造验收和样机性能仍需下面列出的工作。

## 本轮发现及修复

|设计问题|影响|本轮完善|
|---|---|---|
|已给定热点谱的损伤不参与方案判定|一个明确算出`D>1`的输入谱仍可能得到总体初筛通过|增加`fatigue_damage_per_input_history`汇总值和上限；给定谱缺省要求`D<=1`，可配置更严格目标|
|缺少刚度与均载的目标约束|方案比较没有直接排除过软或过度偏载候选的入口|增加最小输出扭转刚度与最大行星均载系数限值，候选须满足已配置约束才能进入可行Pareto比较|
|只有通过/未通过，不能核对判定依据|缺参数或未设目标容易被误读为已经校核|增加`check_details`，逐项输出实际值、阈值、比较方向、范围及四种状态；未评价和未设限值单独登记|
|结构K参考点与力作用点不能区分|输入悬伸力时，使用者可能遗漏其对结构倾转的影响|增加`support.reference_offset_m`，通过保持虚功的载荷/位移变换处理力臂；缺省0保留端口凝聚K的接口|
|工程元数据把各参考点混为一个原点|轴承反力、结构位移与失准映射可能采用不同力臂|分别登记双支承中点、输出载荷端口、K参考点和未给定的齿轮轴向位置|
|装配检查未提供外齿根切风险提示|小齿数能装配不等于能按给定刀具加工|增加零变位标准全齿高齿条的外齿根切风险初筛；实际刀具、内齿干涉与尖顶保持未评估|
|“配置约束通过”的覆盖不清晰|等效刚度、基本L10和功率平衡容易被扩展为零件强度、实物寿命和驱动器认证|增加`assessment_coverage`并在导出报告列出未建模失效模式|
|展示离散较粗、对标层级分散|单一图形无法判断离散误差和证据适用范围|当前生产案例加密为64相位×26条带，并集中公开专业软件单副对标、实物参数核对与独立公式/离散证据，详见[验证说明](validation.md)|

刚度参考点变换采用`uport=B uref`、`Wref=Bᵀ Wport`及`Cport=B K^-1 Bᵀ`，先计入`r×F`再求结构响应。`bearings.load_offset_m`相对双轴承中点，结构偏置相对K参考点，二者不能自动等同。输出载荷按设计需求给定，接入实测作用/反作用载荷时须统一符号；[模型](model.md)与[接口](api.md)给出完整约定。

外齿根切初筛使用标准全齿高齿条关系`z sin²α>=2`，来源为[QTC/KHK技术资料](https://www.qtcgears.com/tools/catalogs/PDF_Q420/Tech.pdf)。它只提示特定假设下的理论风险，不自动否决加工方案。

## 当前案例的设计选择

DFKI公开质量、尺寸和原驱动器参数提供真实需求参照；齿数组合来自公开齿轮组。本项目新增的运动、修形、误差、刚度、效率、热参数、评级因子和S-N数据仍是设计输入。供应页30 mm中心距表述与所给齿数/模数的零变位关系存在差异，当前采用15 mm并保留待确认项，制造前应核对实物尺寸或正式图样。

本轮显式选择`Kout>=20000 N·m/rad`、`Kγ<=2`、给定热点谱`D<=1`，均为**本例假设，不是DFKI实物规格**。结构K定义于输出载荷端口，因此`reference_offset_m=0`；端口相对双轴承中点偏置另设为0.012 m。不同候选重算同一任务，不用旧几何的评级因子冒充新几何自动评级。

64×26是本例采用的求解离散；某个代表工况与更密网格接近，仍不保证所有载荷、边缘接触和其他齿数的峰值均已收敛。采用新几何、修形、误差或材料时，应重复相应离散研究。

## 修订如何验证

|验证对象|检查内容|复算入口|
|---|---|---|
|设计判定|构造`D>1`反例、刚度/均载/损伤不满足目标、缺输入与未配置状态、阈值和实际值一致性|`tests/test_analysis.py`|
|参考点变换|悬伸力产生的解析弯矩/倾转/端口平移、两偏置符号、虚功、柔度互易正定、非法参数|`tests/test_support.py`|
|结构到齿面的接入|真实小型LTCA中检查偏置位移确实进入逐行星失准映射|`tests/test_analysis.py`|
|工程坐标|检查轴承中点、端口、K参考点各自位置，未输入尺寸保持未知|`tests/test_engineering.py`|
|几何风险|标准齿条公式、正常齿数与小齿数风险、内齿未评估状态|`tests/test_planetary.py`|
|原有物理链|正反转平衡、零速保持铜耗、转子惯性功率、基本L10、雨流、热能量与周期闭合|对应`tests/`模块|

```bash
python -m unittest discover -s tests -v
python -m examples.build_showcase --output output/showcase --raw-output output/raw
python -m examples.run_benchmarks --output output/benchmarks
```

普通接口集成测试采用小型实际求解，验证接口与物理关系；完整34工况和高离散结果通过案例命令复算。最终测试执行状态以仓库CI为准。专业软件的单副数值一致、实物公开参数核对、解析方程检查和样机试验分别登记，不相互替代。

## 仍需优先完成的设计工作

|优先级|工作|所需输入与验收证据|
|---|---|---|
|高|标定双向刚度、侧隙和摩擦|扭矩—角度加载/卸载记录、安装边界与编码器标定；用留出载荷验证，不只拟合一条曲线|
|高|完善损耗与热参数|不同转速/载荷的输入输出功率、空载损耗和温升/冷却记录，独立任务验证温度预测|
|高|行星销及行星轴承校核|销径、跨距、材料、销孔接触、轴承型号与相对转速/载荷；等效销刚度不能代替强度或寿命|
|高|制造与实体结构校核|实际齿廓和刀具、齿顶厚度、内齿干涉、轮缘/壳体/行星架、螺栓和配合；需要正式图样及对应结构模型|
|中|输出轴承摆动适用性|预紧/游隙、摆幅和接触覆盖、润滑、微动和假压痕；基本L10的大数值不能当实物寿命|
|中|驱动器与再生母线|电流/电压包络、峰值持续时间、母线电容/吸能或制动电阻；电机功率守恒不证明这些能力|
|中|同步动力学与控制|相位同步啮合、零件惯量、结构模态、控制器及试验频响；准静态刚度不等于闭环带宽|

这些工作未在本轮假定完成。当前输出角度预算是未补偿确定性上界，静态双工作面图不模拟真实迟滞；给定热点谱损伤和输出轴承基本L10也不构成整关节寿命认证。
