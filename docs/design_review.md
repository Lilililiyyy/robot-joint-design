# 关节模组设计审查与完善

[中文](design_review.md) · [English](design_review.en.md)

本次审查从机器人关节的设计需求、功率/载荷传递、刚度精度、失效模式和验证证据出发，检查参数化计算内核及其公开案例。审查结论支持将项目用于**单级直齿NGW关节的准静态设计计算与方案筛选**；完整实体设计、制造验收和样机性能仍需下面列出的工作。

0.3.0增加行星销与行星轴承、再生母线初筛；0.3.1纠正接触显示中混用通过程压力与有限带包络、瞬时带坐标不合适的问题。新增功能的计算、输入假设及物理验证状态分别记录；可选输入缺失时不把对应失效模式记成通过。

## 本轮发现及修复

|设计问题|影响|本轮完善|
|---|---|---|
|已给定热点谱的损伤不参与方案判定|一个明确算出`D>1`的输入谱仍可能得到总体初筛通过|增加`fatigue_damage_per_input_history`汇总值和上限；给定谱缺省要求`D<=1`，可配置更严格目标|
|缺少刚度与均载的目标约束|方案比较没有直接排除过软或过度偏载候选的入口|增加最小输出扭转刚度与最大行星均载系数限值，候选须满足已配置约束才能进入可行Pareto比较|

|工程元数据把各参考点混为一个原点|轴承反力、结构位移与失准映射可能采用不同力臂|分别登记双支承中点、输出载荷端口、K参考点和未给定的齿轮轴向位置|
|装配检查未提供外齿根切风险提示|小齿数能装配不等于能按给定刀具加工|增加零变位标准全齿高齿条的外齿根切风险初筛；实际刀具、内齿干涉与尖顶保持未评估|
|“配置约束通过”的覆盖不清晰|等效刚度、基本L10和功率平衡容易被扩展为零件强度、实物寿命和驱动器认证|增加`assessment_coverage`并在导出报告列出未建模失效模式|
|展示离散较粗、对标层级分散|单一图形无法判断离散误差和证据适用范围|当前生产案例加密为64相位×26条带，并集中公开专业软件单副对标、实物参数核对与独立公式/离散证据，详见[验证说明](validation.md)|
|接触显示的物理量与坐标缺少源项目核对|节点图不能代表通过程；瞬时微米带在整齿毫米轴上失真；有限带包络不等于源项目显示|采用源项目材料坐标三角线性插值和等压线，局部瞬时带另用mm/μm坐标；以相同18/77原网格逐点核对，原基准与修形诊断分开，见[接触说明](contact_patterns.md)|
|等效销刚度没有对应零件强度与行星轴承检查|系统分载通过不能说明销弯曲/横剪/孔压或行星轴承可用|新增显式简支圆实销的弯剪、挠度和平均接触面压，行星轴承使用真实销反力与相对行星架转速做基本评级；不隐式回写系统刚度|
|回驱功率没有变成母线吸能需求|负机械功率与真实电回馈混淆，可能遗漏母线过压|以含铜损及转子惯性的电机电功率，新增双向逆变损耗、分段电容能量、阈值事件和外部吸收上限初筛，见[母线模型](dc_bus.md)|

刚度参考点变换采用`uport=B uref`、`Wref=Bᵀ Wport`及`Cport=B K^-1 Bᵀ`，先计入`r×F`再求结构响应。`bearings.load_offset_m`相对双轴承中点，结构偏置相对K参考点，二者不能自动等同。输出载荷按设计需求给定，接入实测作用/反作用载荷时须统一符号；[模型](model.md)与[接口](api.md)给出完整约定。

外齿根切初筛使用标准全齿高齿条关系`z sin²α>=2`，来源为[QTC/KHK技术资料](https://www.qtcgears.com/tools/catalogs/PDF_Q420/Tech.pdf)。它只提示特定假设下的理论风险，不自动否决加工方案。

## 当前案例的设计选择

DFKI公开质量、尺寸和原驱动器参数提供真实需求参照；齿数组合来自公开齿轮组。本项目新增的运动、修形、误差、刚度、效率、热参数、评级因子和S-N数据仍是设计输入。供应页30 mm中心距表述与所给齿数/模数的零变位关系存在差异，当前采用15 mm并保留待确认项，制造前应核对实物尺寸或正式图样。

本轮显式选择`Kout>=20000 N·m/rad`、`Kγ<=2`、给定热点谱`D<=1`，均为**本例假设，不是DFKI实物规格**。结构K定义于输出载荷端口，因此`reference_offset_m=0`；端口相对双轴承中点偏置另设为0.012 m。不同候选重算同一任务，不用旧几何的评级因子冒充新几何自动评级。

64×26是本例采用的求解离散；某个代表工况与更密网格接近，仍不保证所有载荷、边缘接触和其他齿数的峰值均已收敛。采用新几何、修形、误差或材料时，应重复相应离散研究。

## 继续推进后的设计结论

**接触显示。** 本轮撤回0.3.0把有限Hertz带包络当作源项目通过程图、以及相关“无插值”的表述。新图按源项目`contact_pass_data`方法显示原局部峰压及等压线，凸包外为NaN；仅中心数据的边界支撑和独立端点解严格区分。瞬时带用沿接触线mm、垂线μm，不能拿图面面积或长宽比判断实体承载面积。独立端点分别插值峰压和半宽，显示面积积分不保证等于原条带合力；原力、显示积分及差异分别报告，不归一化压力。主案例仍在冻结局部载荷下采用512相位×41条带，保留各工况/行星/构件身份，不是1.8 s任务最大压力或新增二维/FE解。

**模型与显示分别审查。** 默认ISO直齿、零齿廓鼓形案例的单/双齿切换仍会产生压力分区，不为椭圆外观暗改主流程。另选`negative_peak/sun_planet/planet02`，实际比较ISO控制基准、仅Love及每轮鼓形替换为3 μm+Love三组。控制基准显式强制ISO、`local_contact=False`和128×21，`source_analysis_input`与`baseline_changes_from_source`记录来源和改动，不能把任意自定义来源当作未修改基准；非`parameters`组合修形报错。它报告压力过渡、法向趋近与刚度代价，尚非制造修形建议或优化。18/77相同输入在原30×30显示网格逐点核对压力与掩码；上游显示方法再现误差和MASTA对标误差分别报告。一般回归测试通过不再被用作斑点物理正确性的证明，详见[方法、数据与边界](contact_patterns.md)。

**销与行星轴承。** 当前载荷给出最大销反力118.889 N。新增4/6 mm销、12 mm简支跨距、5 mm加载宽度等设计假设后，两者静筛通过，但功共轭平均弯剪刚度为71.225/297.707 MN/m，分别约为原系统300 MN/m的0.2374/0.9924。4 mm销即使应力通过，也不能继续无依据地沿用原刚度；应显式反馈其适用结构刚度并重算。6 mm数值接近也不是刚度标定。两销L/d仅为3和2，已纳入横剪柔度仍需三维销孔/支承模型。假定轴承容量所得基本L10只作公式初筛，不能替代摆动损伤与采购选型，详见[行星支承](planet_support.md)。

**再生母线。** 同一电机历程在新增36 V源、48 V上限和96%双向逆变效率假设下，470 μF无吸收得到自由能量推算峰值83.624 V，超过约束；4700 μF为43.194 V，470 μF加15 W外部吸收则为36 V。真实控制器可能在越限时关断，越限后的曲线不预测硬件实际电压。回馈峰值/总能量为13.398 W/2.678 J，名义起始无吸收所需最低电容约2656 μF。这补上了能量初筛，但未完成有限电源能力、真实驱动器电压/电流包络、电阻热容量或保护验证，详见[母线说明](dc_bus.md)。

## 仍需优先完成的设计工作

|优先级|工作|所需输入与验收证据|
|---|---|---|
|高|标定双向刚度、侧隙和摩擦|扭矩—角度加载/卸载记录、安装边界与编码器标定；用留出载荷验证，不只拟合一条曲线|
|高|完善损耗与热参数|不同转速/载荷的输入输出功率、空载损耗和温升/冷却记录，独立任务验证温度预测|
|高|将销/行星轴承初筛落实到真实零件|确认销径/跨距/材料、销孔三维接触与真实轴承型号，反馈适用刚度重算；基本评级不能代替摆动寿命|
|高|制造与实体结构校核|实际齿廓和刀具、齿顶厚度、内齿干涉、轮缘/壳体/行星架、螺栓和配合；需要正式图样及对应结构模型|
|中|输出轴承摆动适用性|预紧/游隙、摆幅和接触覆盖、润滑、微动和假压痕；基本L10的大数值不能当实物寿命|
|中|验证驱动器与实际母线吸收装置|在已有能量初筛之上核对有限电源、电流/电压包络、峰值持续时间、纹波、保护与电阻热容量；需具体硬件和试验|
|中|同步动力学与控制|相位同步啮合、零件惯量、结构模态、控制器及试验频响；准静态刚度不等于闭环带宽|

上表列的是仍未完成的具体物理/制造验证，已有销/行星轴承和母线初筛分别保留其输入与状态。当前输出角度预算是未补偿确定性上界，静态双工作面图不模拟真实迟滞；给定热点谱损伤和基本L10也不构成整关节寿命认证。完整通过程压力图同样不代表样机测得接触印痕。
