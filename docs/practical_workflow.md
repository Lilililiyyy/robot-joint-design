# 如何用于一个真实关节设计

[中文](practical_workflow.md) · [English](practical_workflow.en.md)

本项目当前适合单级直齿NGW关节的参数计算、任务初筛及方案比较。要把结果用于具体模组，首先建立有依据的输入，再让计算、结构分析和实物试验相互核对。公开案例是使用方法和假设的示范，不能替代目标产品参数。

## 最小输入包

|输入|需要准备的实际资料|计算中的位置|
|---|---|---|
|任务与安装|负载质量/惯量、重力方向、轨迹、急停和保持需求、六分量载荷参考点|`duty_segments`、`support`、`bearings`|
|齿轮与材料|实齿数/模数/齿宽、材料热处理、齿面质量、修形及标准评级因子依据|`stage`、`mesh`、`rating`|
|销与架板|销径/跨距/加载范围、边界约束、孔位与配合、架板变形|`planet_support`、支承K或额外凝聚柔度|
|轴承|实际目录型号、C/C0、旋转圈及X/Y/X0/Y0分支、预紧、润滑与摆角|输出及行星轴承评级输入；摆动服役仍单独评价|
|电机与驱动|同一电流定义的Kt和R、转矩转速限制、温度降额、回馈及保护能力|`motor`、`drive`、`dc_bus`|
|验收目标|输出刚度、角度预算、允许压力/应力、温升、静安全及寿命要求|`design_limits`及情景`required_checks`|

每项采用值应保留来源、单位和适用条件。未掌握的值应保留为明确假设，开展敏感性比较；不要把案例常量直接当成产品数据。

## 实施顺序

1. 用完整载荷任务运行`analyze_joint`，核对正反转矩、作用/反作用、SI单位及坐标。首先查看未评价/未配置的项目，确认所需判据均已覆盖。
2. 从约束表查看有符号裕量，并用`constraint_margins.json`定位危险任务段、行星和齿轮副。对局部峰压等离散结果，在危险状态另做相位/条带收敛核查。
3. 把实际装配误差或结构刚度边界映射为[有限情景](design_envelope.md)，重新求解完整任务。情景失败时修改相应支承/装配方案；名义值通过不作为边界变化通过的依据。
4. 使用计算反力开展销孔、架板、内齿圈和箱体结构分析。凝聚柔度接入前明确参考点、自由度和单位，排除已经计入的销、齿面和太阳支承。
5. 确认采购轴承、材料许用值、电机驱动与母线实际能力；改变销径后重新选轴承，不能沿用示例容量宣称完成选型。
6. 按同一扭矩、角度、转速和温度基准做样机试验，再修订支承、损耗和热参数。正反加载、保持与循环温升分别保存原始测量，未完成试验前保持数值验证状态。

## 当前能力与后续优先级

|事项|当前提供|仍需补充|
|---|---|---|
|任务与准静态接触|完整任务、两副LTCA、分载、反力及原始接触数组|实际负载边界；危险状态的离散收敛确认|
|设计决策|约束裕量、危险位置、有限装配/支承情景比较|真实公差投影；连续域最坏点和统计模型尚未实现|
|实测闭环|参数接口及原响应导出|优先增加双向扭转、效率及温升测量导入与参数识别|
|支承结构|六自由度K和路径凝聚柔度接口|优先接入实际架板/轮缘/箱体分析及参考坐标核验|
|采购与制造|参数级CAD/BOM、显式容量及评级|实际零件库、配合/预紧、加工及装配图样|
|服役与动态|基本L10、给定热点谱疲劳、准静态输出刚度|摆动轴承损伤、扭转动态及总成耐久试验|

后续优先做实测数据闭环、真实结构柔度和采购级选型。它们直接决定模型能否代表装配后的模组；在这些输入缺失时，继续增加图表或把单副对标推广为总成验证不能提高设计依据。
